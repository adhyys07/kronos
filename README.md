## Kronos
Kronos is a split gaming keyboard with RGB keys support powered by XIAO-nRF52840-SMD, it uses two of the xioa board for the left and right side and it's a complete wireless keyboard that coan be connected to your devices easily. I am also gonna try to make a dedicated firmware + software for the keyboard although I am not sure for it but I would really like to make one.
